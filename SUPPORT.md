# Support

Use [GitHub Issues](https://github.com/tjdgus903/spring-config-guard/issues) for bug reports, feature
requests, documentation corrections, and compatibility questions. Search existing issues before opening
a new one.

## Include in a report

- Spring Config Guard version and the exact IntelliJ product/version
- operating system and JDK version
- whether the problem occurs in an editor inspection, a **Tools** action, or the optional commit warning
- minimal reproduction steps, expected behavior, and actual behavior
- relevant error text, screenshots, or a GitHub Actions run/commit SHA when applicable

Redact credentials, tokens, endpoints, personal data, and configuration values before posting. Do not
attach live project configuration or logs that may contain secrets.
